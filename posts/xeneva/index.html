Open Source Friday #25 - XenevaOS

Published on: 2026-09-25

Tags: Operating Systems XR IndiaFOSS OSF

As you all know, Indiafoss starts tomorrow (technically today)! As a precursor, I wanted to highlight an organization /company that will be speaking on Sunday.

XenevaOS is an XR-native operating system built from scratch on its own custom hybrid kernel called "Aurora".

Overview & Core Custom Architecture
- Kernel: Powered by the independent Aurora kernel written in C, C++, and Assembly, avoiding legacy code dependencies.
- Target Hardware: Designed for spatial computing and Extended Reality (XR/AR/VR) devices like lightweight smart glasses, while supporting x86_64 and ARM64 architectures.
- Graphics & UI: Features a custom graphics library (Chitraka) and a compositing window manager (Diodai / Deodhal) that handles window management and smooth visual transitions.
- System Utilities: Includes a functional desktop environment complete with a shell terminal, file manager, music player, calendar, and font rendering via FreeType2.

All of this started as a hobby 6 years ago, and now is a fully blown open source company.

If you wanna know how they are surviving as an OSS company, do check them out on Sunday at Indiafoss :D
