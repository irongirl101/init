Everyone here (I hope) has an idea of what Linux is, and how peak of an Operating System it is. Instead of going in depth on what the repo contains, i wanna highlight on some fun facts about Linux.
- Way back in the 90s, on RedHat specifically, there was a config/setup to attempt an auto detect of the sound card and then play a sound sample. It played Linus Torvalds actually saying, "I am Linus Trovalds, and I pronounce Linux as 'Linux' "
- At its peak (2.6), there were around 70 F-bombs in the kernel code, its now come down to just 20 D: [lookie here for some fun stats on funni words, including 'penguin' or for 'shit' - or ]
- Literally EVERYTHING is a file -- including stuff like the activity of mouse, speaker, and monitor; you can probably do some very funky stuff XP
- It has insult support: If you use sudo visudo to open the sudo config file and add Defaults insults then every time you incorrectly type your sudo password, it gives you a random insult. (You might need to restart your session)
- There were plans to call Linux as 'FreaX'
- you can -rm a running file on linux
Theres so much more cool stuff, which you can find on Linux, which i possibly cannot fit here. I encourage yall to look for more easter eggs, and some fun stuff Linux can do!
