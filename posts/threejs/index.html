Open Source Friday #3 - three.js

Published on: 2026-04-24

Tags: javascript library three.js docs OSF

What is three.js?¶

three.js is an an easy-to-use, lightweight, cross-browser, general-purpose 3D library. It acts as a high-level abstraction layer over WebGL, allowing developers to build complex 3D scenes using standard JavaScript without needing to write low-level, specialized graphics code

It is primarily built using Javascript (67%), HTML (30%), Roff and CSS (3%).

What are some key features of three.js?¶

  • Simplified WebGL: It wraps the complexities of WebGL (which handles low-level tasks like points and lines) into an intuitive API for handling lights, materials, and 3D objects.
  • Rendering Capabilities: While primarily used with WebGL, it also supports WebGPU, SVG, and CSS3D renderers.
  • 3D Components: Includes built-in support for scenes, perspective and orthographic cameras, diverse light sources (ambient, spot, directional), and various materials (Lambert, Phong, PBR).
  • Asset Loading: Allows developers to import 3D models created in professional software like Blender via formats like glTF, OBJ, and USDZ.
  • WebXR Support: Enables the creation of Virtual Reality (VR) and Augmented Reality (AR) experiences directly in the browser.

This tool is highly useful while trying to build games on browsers, creation of interactive 3D models on websites, data visualization and even architucture.
